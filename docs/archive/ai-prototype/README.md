# Pausierter KI-Prototyp

Am 3. September 2026 wurde KI auf Nutzerwunsch vorerst aus Rowivo entfernt. Die aktuelle App verwendet einen manuellen Trainingseditor.

Die Swift-Dateien in diesem Ordner sind historische Quellen. Sie gehören nicht zum App-Target und werden nicht kompiliert. Der alte Netzwerkclient, die Keychain-Anbindung und die Coach-Oberfläche sind hier nur für eine mögliche spätere Neubewertung aufbewahrt. Auch die früheren Produkt- und Implementierungsbeschreibungen sind historisch.

Alte lokale Daten bleiben lesbar: optionale Trainingsnamen erhalten die Kompatibilität, bestehende Trainings und Aufzeichnungen werden übernommen. Legacy-Chatfelder bleiben im lokalen Datenschema erhalten. Frühere KI-Freigaben und offene Vorschläge werden beim Öffnen deaktiviert. Ein früher gespeicherter Schlüssel wird von der App nicht mehr gelesen oder verwendet.
